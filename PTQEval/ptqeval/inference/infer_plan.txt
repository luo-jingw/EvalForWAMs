核对发现 (影响设计):
F1 w4a4 是「权重量化 + QuaRoT」，data-free：w4a4.yaml smooth_quant=false、无
   calib_data_path，激活为运行时 per-token 动态量化。=> 生成 w4a4 权重
   不需要 calib_data，只需 FP transformer + w4a4 配置。(D2 的 calib 对 w4a4
   非必需；仅 smooth_quant 类配置才需要。)
F2 VA_Server 依赖 dist 进程组 (init_distributed nccl env://)。单卡机器人需
   引擎在构建前做一次单进程 bootstrap (world_size=1)。量化路径跳过 FSDP。

===============================================================================
2 系统结构 (模块 + 职责 + 状态归属)
===============================================================================
M1 weight_prep   FP(bf16) + w4a4 配置 -> int_weights.pth。薄封装 ptq.py。
                 data-free (F1)。离线(远程)运行。归属: 量化权重(磁盘)。
M5 precompute    prompt(s) -> 文本 embed 缓存 (T5 编码一次)。离线运行。
                 归属: 文本 embed 缓存(磁盘)。专用文件 (D1)。
M2 config        部署参数显式载体 (dataclass) + yaml；以 va_robotwin_cfg 为底覆盖。
                 归属: 运行参数(唯一真源，只读)。
M3 engine        单进程 dist bootstrap (F2) + 构建量化模型(loader)+VAE+文本注入；
                 转发 reset/infer/compute_kv_cache 到 VA_Server。
                 归属: 模型 + KV cache + prompt_embeds(运行时)。
M4 metrics       (可选) 包裹引擎：整体 peak VRAM + 每次 infer 墙钟时间。观测型。
                 归属: 观测量。
[待办 D3] server 适配层：拿到接口后新增 inference/server_*.py，仅调用 M3。

关键状态唯一归属: 参数只属 M2；模型/cache 只属 M3；M4 只观测。

===============================================================================
3 接口设计 (输入 / 输出 / 状态变化)
===============================================================================
M1 weight_prep.build_int_weights(
       fp_transformer_dir: str, output: str,
       layer_config: str = <inference/configs/w4a4.yaml 或指向 method/viditq>,
       device: str = "cuda:0") -> str
   复用: subprocess 调 method.viditq.ptq (与 derive_calib_ptq 同法)，不复制算法。
   无 calib_data 参数 (F1)。输出 int_weights.pth 路径。仅写磁盘。

M5 precompute.build_text_cond_cache(
       prompts: list[str], model_path: str, output: str,
       device: str = "cuda:0") -> str
   复用: text_cond_cache.store_cache + T5 编码 (同 precompute_text_cond 的
   encode 逻辑，独立成部署文件)。编码含空负样本 ""。输出缓存路径。仅写磁盘。

M2 InferenceConfig (dataclass，全字段类型标注):
   model_path: str                 # FP transformer 目录 (transformer/ vae/ text_encoder/)
   int_weights_ckpt: str = ""      # M1 产物；空 -> bf16 基线
   layer_config: str = ""          # w4a4 配置；空 -> bf16
   variant: str = "viditq"
   text_cond_cache: str = ""       # M5 产物 (T5-free 注入)
   serve_residency: bool = False   # 串行注入 (miss 时 transformer 让位 T5) (D1)
   offload_target: str = "cpu"     # 串行/直算时 transformer 卸载去处 cpu|disk
   offload_dir: str = ""
   attn_window: int = 72           # 滑窗，默认 72 (与原设计一致)
   guidance_scale: float = 5.0; action_guidance_scale: float = 1.0
   num_inference_steps: int = 25; action_num_inference_steps: int = 50
   dtype: str = "bf16"; device: str = "cuda:0"
   enable_offload: bool = True     # VAE/text_encoder 常驻 CPU 省显存
   save_root: str = "/tmp/va_infer"
   env_type: str = "robotwin_tshape"   # (D4)
   classmethod from_yaml(path) -> InferenceConfig
   to_job_config() -> EasyDict     # copy(VA_CONFIGS['robotwin']) + 覆盖上述字段
                                   # + 写临时 variant_args yaml(int_weights+layer_config)

M3 InferenceEngine(config: InferenceConfig):
   __init__: 单进程 dist bootstrap (MASTER_ADDR/PORT/RANK/WORLD_SIZE + init_distributed)
             -> 构建 job_config -> VA_Server(job_config)。
   infer(request: dict) -> dict    # 直接转发 VA_Server.infer；按 request 键三分支
                                   # (reset / compute_kv_cache / else)。与未来 server 同形。
   reset(prompt: str | None) -> None   # 便捷: infer({'reset':True,'prompt':prompt})
   状态变化: reset 重置 KV cache + prompt_embeds；infer 推进。

M4 metrics.MeasuredEngine(engine):
   infer(request) -> dict          # 透传，记录墙钟
   peak_alloc_mb() -> float        # torch.cuda.max_memory_allocated
   last_infer_ms() -> float; reset_peak() -> None
   观测型，无阈值判定 (principle L12)。

===============================================================================
4 运行流程
===============================================================================
离线 (远程/工作站):
  (a) M1: FP(bf16) + w4a4 配置 -> int_weights.pth (data-free)。
  (b) M5: 部署 prompt -> 文本 embed 缓存 (T5 编码一次)。
机器人 (clone 本包):
  启动: M2 读 config -> M3 dist bootstrap -> 加载 FP transformer(loader: FP+int
        overlay) + VAE(可选 offload) + 文本缓存。全程不常驻 T5。
  每 episode: reset(prompt) -> loop[ infer(obs)->action ; infer(compute_kv_cache) ]。
  文本注入: 命中缓存直接注入 (T5-free)；未命中且 serve_residency -> 串行编码。
  可选: M4 记录整体 peak + infer 时间。
cache 更新: VA_Server 内部 create_empty_cache/clear_cache (复用)。
